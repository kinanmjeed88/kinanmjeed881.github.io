# TechTouch Hub

بوابة TechTouch الرسمية لقنوات Telegram والتطبيقات والألعاب ووسائل التواصل الاجتماعي.

## 📁 إدارة المحتوى

### 1. 📰 إضافة مقال جديد (Articles)
لإضافة مقال جديد يظهر في قسم "المقالات":
1. اذهب إلى المجلد `data/articles.ts`.
2. داخل مصفوفة `articlesData`، أضف كائن جديد بالتنسيق التالي:
```typescript
{
  id: 7, // رقم فريد جديد
  title: "عنوان المقال الجديد",
  date: "2025-02-01",
  content: `
  [هذا عنوان فرعي]
  اكتب نص المقال هنا...
  
  [عنوان فرعي آخر]
  إذا وضعت رابط يوتيوب هنا (https://youtu.be/... أو shorts) سيظهر الفيديو مباشرة.
  
  أي رابط آخر سيتحول تلقائياً إلى كلمة "اضغط هنا" باللون الأزرق.`
},
```
3. **الميزات التلقائية:**
   - **العناوين الفرعية:** ضع النص بين قوسين مربعين `[النص]` ليظهر كعنوان مميز وبارز داخل المقال.
   - **فيديو يوتيوب:** يدعم الآن الفيديوهات العادية، Shorts، وروابط المشاركة المختصرة (youtu.be).
   - **الروابط:** يتم إخفاء الرابط الطويل واستبداله بكلمة "اضغط هنا" قابلة للنقر.
   - **المشاركة:** زر المشاركة في أعلى المقال ينسخ رابطاً مباشراً للمقال (Deep Link).

### 2. 📱 إضافة هاتف جديد (Phones Database)
توجد بيانات الهواتف في المجلد `data/phones-backup/`. لإضافة هاتف جديد:
1. اختر ملف الشركة المناسب (مثلاً `samsung.json` أو `apple.json`).
2. أضف بيانات الهاتف الجديد داخل مصفوفة `phones`.

### 3. 🖼️ إضافة الصور (Profile Picture)
لتغيير الصورة الشخصية:
1. ضع الصورة في المجلد `public/`.
2. سمّ الصورة `profile.jpg`.
3. تأكد من إعدادات `profileConfig` في ملف `data/content.ts`.

### 4. 📢 القنوات والمجلدات (Telegram Channels)
لإضافة قناة أو مجلد تيليجرام:
1. افتح الملف `data/content.ts`.
2. أضف القناة في مصفوفة `telegramChannels`.

## 🚀 التشغيل والتطوير
- تشغيل السيرفر المحلي: `npm run dev`
- بناء المشروع: `npm run build`

## ✅ دليل حل مشكلة 404 /src/index.tsx وضمان التوافق الكامل مع GitHub Pages

### 📌 المشكلة الأساسية (Root Cause)
ظهور الخطأ:
```
GET https://username.github.io/src/index.tsx 404
```
يعني أن الموقع المنشور يحاول تحميل ملفات التطوير (`src`) بينما GitHub Pages يخدم فقط ناتج البناء (`dist`).

**❗ هذا الخطأ الواحد يسبب:**
- بقاء Spinner (شاشة التحميل).
- فشل تحميل React.
- أخطاء manifest.
- شاشة فارغة.

### 🧠 القاعدة الذهبية
GitHub Pages لا يعرف `src/`، يعرف فقط `dist/`. إذا ظهر `/src` في DevTools ← الموقع مكسور حتمًا.

### 🛠️ الحل الصحيح (خطوات ثابتة)

#### 1️⃣ ضبط vite.config.ts
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: '/kinanmjeed881.github.io/', // اسم المستودع بالضبط
})
```
**📌 مهم جدًا:** الاسم حساس للحروف ويجب أن يطابق رابط المشروع.

#### 2️⃣ تصحيح index.html
يجب أن يحتوي `index.html` في المشروع على الأساسيات فقط، مع ترك مهمة ربط السكربتات لـ Vite أثناء البناء.
**❌ احذف نهائيًا:**
- أي `importmap`.
- أي ربط يدوي معقد بـ `src` يتجاوز السكربت القياسي.

#### 3️⃣ إزالة أي importmap (إن وُجد)
`importmap` قد يسبب تعارضاً في تحميل الوحدات في الإنتاج، مما يؤدي لتعليق التطبيق.

#### 4️⃣ تنفيذ البناء محليًا
```bash
npm run build
```
يجب أن يتم إنشاء مجلد `dist/` يحتوي على `index.html` و `assets/`، و **لا** يحتوي على `src`.

#### 5️⃣ النشر على GitHub Pages (الطريقة الصحيحة)
تأكد أن GitHub Actions يرفع مجلد `dist` فقط:
```yaml
- name: Upload artifact
  uses: actions/upload-pages-artifact@v3
  with:
    path: ./dist
```

### 🔍 قائمة التدقيق بعد النشر (Checklist)
**افتح DevTools → Network:**
- ✔️ يجب أن ترى: `/assets/index-xxxx.js`.
- ❌ يجب ألا ترى: `/src/index.tsx`.

**سلوك الصفحة:**
- ✔️ Spinner يختفي.
- ✔️ React يعمل.
- ✔️ التنقل يعمل.

### 🧩 لماذا ظهرت أخطاء كثيرة؟
لأنها أعراض لمشكلة واحدة فقط. إذا لم يتم تحميل React (بسبب طلب الملف الخاطئ)، كل شيء بعده يفشل وينهار المتصفح بسلسلة أخطاء.

### ✅ الخلاصة النهائية
المشكلة ليست في GitHub ولا في Tailwind ولا TypeScript. **هي فقط تحميل src في الإنتاج.** بمجرد إصلاح ذلك، الموقع يعمل فورًا.
